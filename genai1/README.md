# Python Collections Assignment

This project demonstrates the use of different Python collection data types and their operations.

## Task 1 - Lists and Tuples
This task demonstrates:
- Creating and using lists
- Accessing list elements
- Adding and removing items
- Creating tuples
- Difference between lists and tuples

## Task 2 - Sets
This task demonstrates:
- Creating sets
- Removing duplicate values
- Performing basic set operations
- Understanding unique collections in Python

## Task 3 - Dictionaries
This task demonstrates:
- Creating dictionaries
- Adding and updating key-value pairs
- Deleting dictionary items
- Using conditional checks for safe deletion

## Task 4 - Combined Operations
This task combines concepts from previous tasks and demonstrates:
- Importing data from another Python file
- Using lists, tuples, sets, and dictionaries together
- Creating product-category mappings
- Grouping products by category
- Finding the category with the highest number of products
