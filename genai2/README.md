# Python Programming Assignment

This project contains Python programs demonstrating the use of:
- Conditional statements
- Loops
- Functions
- Lists
- Error handling
- Menu-driven programs

# Topics Covered

## Task 1 - Discount Rules
This program demonstrates:
- Taking user input using `input()`
- Using `if / elif / else`
- Applying discounts based on order amount
- Calculating discounted amount
- Handling invalid input using `try-except`

Concepts used:
- Conditions
- Variables
- Arithmetic operations
- Error handling
